# Cryptonly Medusa Assets

`cryptonly-medusa-icon.png` (and `.svg`) is the square brand icon for npm, GitHub, and
Medusa integration-directory submission or curation requests.

`storefront/cryptonly.tsx` is a reference React icon for the Medusa Next.js starter
`paymentInfoMap` (copy into your storefront). Checkout icons are not injected by the
provider — merchants map the provider in their storefront.
